# Primeiro Segundo Projeto de Git / GitHub

Projeto simples, desenvolvido unicamente para aprender conceitos e utilizações de Git e GitHub.

## Funcionalidades

- Função soma
- Função subtração
- Função multiplicação
- Função divisão
- Função fatorial

## Tecnologias
- C
- Git
- GitHub

## Conceitos Aprendidos
- Comandos Git
- Staging Area
- Trabalho em Equipe (Repository, Pull Request, Issues, Code Review)
- Organização de Projeto (GitHub, Labels, Milestones, README, Wiki e Releases)
