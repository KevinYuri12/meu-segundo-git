# Projeto de Aprendizado — Git e GitHub

Projeto desenvolvido em **C** com o objetivo de praticar, de forma progressiva, conceitos de **Git e GitHub**, desde o controle de versão local até colaboração, organização de projetos e gerenciamento de versões.

## 🎯 Objetivo

Este projeto foi utilizado como ambiente de prática para aprender e aplicar conceitos fundamentais de desenvolvimento colaborativo com Git e GitHub.

## ⚙️ Funcionalidades

O programa possui funções para:

* Soma
* Subtração
* Multiplicação
* Divisão
* Fatorial

## 🛠️ Tecnologias

* **C**
* **Git**
* **GitHub**

## 📚 Conceitos praticados

### Git

* Repositórios
* Commits
* Staging Area
* Branches
* `merge`
* Resolução de conflitos
* `push`
* `pull`
* `fetch`
* Rastreamento de branches remotas

### GitHub

* Repositórios remotos
* Pull Requests
* Code Review
* Issues
* Labels
* Milestones
* GitHub Projects
* README
* Wiki
* Releases

## 🌿 Estratégia de Branches

Durante o desenvolvimento foram utilizadas branches independentes para implementar funcionalidades específicas.

Exemplo:

```text
main
├── feature-soma
├── feature-divisao
└── feature-multiplicacao
```

As funcionalidades foram desenvolvidas separadamente e posteriormente integradas à branch principal por meio de `merge` e Pull Requests.

## 🔀 Fluxo de desenvolvimento

O projeto também foi utilizado para praticar um fluxo de desenvolvimento baseado em:

```text
Criar branch
     ↓
Desenvolver funcionalidade
     ↓
Commit
     ↓
Push
     ↓
Pull Request
     ↓
Code Review
     ↓
Merge
     ↓
Atualizar main
```

Este projeto representa uma etapa prática do meu aprendizado em **controle de versão e desenvolvimento colaborativo**, servindo como base para projetos futuros utilizando Git, GitHub e ferramentas de automação.
